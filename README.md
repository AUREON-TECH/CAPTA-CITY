# CAPTA CITY

**Conquiste pontos. Leve casais. Domine a cidade.**

CAPTA CITY é um jogo multiplayer de tabuleiro e estratégia inspirado na rotina de captação. Os jogadores rodam dados, atravessam a cidade, coletam casais, chegam à Sala, resolvem Q/NQ, geram vendas e VGV, dominam territórios e disputam o maior CAPTA SCORE.

## Status
